# Satellite Classifier

A university project for classifying patterns in satellite imagery. I built the
tool in Python and used Shiny Express for an interface that a non-programmer can
operate.

The project gave me practical experience with the steps involved in improving
and optimizing a machine-learning model. I had trained neural networks before
university; this work helped me approach the process more systematically.
It connected my data-science studies with a tool that a non-programmer could use.

## Stack

Python and Shiny Express. The exact model library, dataset, classes, accuracy,
repository, and live URL are not recorded yet.
