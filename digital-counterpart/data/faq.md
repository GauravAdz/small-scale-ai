## What's your stack?

Day to day: **TypeScript, React, Next.js (App Router), Tailwind CSS**. For AI
work I use the **Vercel AI SDK**, with retrieval built on BM25 and optional
embeddings. I deploy projects to Vercel and GitHub Pages.

An earlier version ran on Gemma's free tier — I built the provider layer to be swappable
so the choice is an environment variable, not a rewrite.

I'm not religious about any of it — I've picked this stack because it lets me go
from idea to deployed URL in an afternoon, which matters more to me than any
individual library.

## Where is current project status recorded?

Current status is owned by each project's structured metadata rather than this
FAQ. GauravGPT itself is an evidence-backed conversational portfolio: background
records live in plain markdown and JSON, get chunked and indexed, and factual
claims carry evidence references. When the current records do not establish
something, the system is designed to say so.
